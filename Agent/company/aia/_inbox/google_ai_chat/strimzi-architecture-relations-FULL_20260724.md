วาง URL ที่ก๊อปปี้มาจาก Teams ลงไป แล้วกด Test เพื่อทดสอบว่ามีข้อความเด้งเข้า Teams ไหม ถ้าเด้งแล้วกด Save contact point   กรณีส่งเข้า Email: ข้อควรระวัง: ตัว Grafana เองต้องมีการตั้งค่า SMTP (Mail Server) ไว้ในไฟล์คอนฟิกหลัก ( grafana.ini ) ก่อนนะครับ ถึงจะส่งเมลออกได้ ถ้าแอดมินตั้งค่า SMTP ไว้แล้ว ให้เลือก Integration เป็น Email ใส่เบอร์เมลผู้รับ (เช่น admin@company.com ) กด Test ดูว่าเมลเข้าไหม แล้วกด Save contact point   ขั้นตอนที่ 2: สร้างเงื่อนไขการเตือน (Alert Rules)   เมื่อมีช่องทางส่งแล้ว ทีนี้เราจะไปผูกกับกราฟสถิติต่าง ๆ โดยไปที่เมนู Alerting ➔ Alert rules ➔ กด + Create alert rule   Enter alert rule name: ตั้งชื่อการแจ้งเตือน เช่น Kafka Broker CPU High   Define query and alert condition: ดึงข้อมูลจาก Prometheus (หน้าตาจะเหมือนตอนที่คุณวาดกราฟ) เช่น ใส่คำสั่ง PromQL เช็ก CPU หรือเช็กความจุของ Kafka Cluster ตั้งค่าเงื่อนไข (Expression) เช่น "Is Above 85" (ถ้าค่าเกิน 85 ให้เตือน)   Set evaluation behavior: Evaluate every: ให้ระบบเช็กข้อมูลทุก ๆ บ่อยแค่ไหน (เช่น ทุก 1 นาที) For: ต้องเกิดปัญหานานแค่ไหนถึงจะเตือน (เช่น ถ้า CPU พุ่งแป๊บเดียว 10 วินาทีแล้วลง ไม่ต้องเตือน แต่ถ้าพุ่งค้างเกิน 5 นาทีค่อยเตือน เพื่อลด Alert หลอก)   Configure notifications: เลือก Contact Point ที่เราสร้างไว้ในขั้นตอนแรก (เช่น เลือกส่งเข้าทีม teams-cluster-alert )   กด Save rule and exit เป็นอันเสร็จสิ้น   💡 ข้อดี & ข้อจำกัด (ที่ต้องรู้ก่อนใช้งานจริง) ข้อดี: ง่ายและเร็วมาก: ตั้งค่าเสร็จภายใน 10 นาทีผ่านหน้าเว็บ ไม่ต้องแก้โค้ด ไม่ต้องขยับ Resource ฝั่งเซิร์ฟเวอร์ เห็นภาพชัดเจน: ตอนตั้งค่าใน Grafana จะมีกราฟจำลองให้ดูเลยว่า ถ้าตั้งเงื่อนไขแบบนี้ ในอดีตมันจะเคยเตือนไปกี่ครั้ง   ข้อจำกัด: กินแรง Grafana (ถ้ามี Alert เยอะมาก): เนื่องจากการเช็ก Alert ของ Grafana คือการส่งคำสั่ง (Query) วิ่งไปถาม Prometheus ทุก ๆ 1 นาที หากในอนาคตคุณมี Alert เป็น 100-200 ตัว ตัว Grafana เองอาจจะทำงานหนักขึ้นครับ (แต่สำหรับช่วงเริ่มต้น หรือมี Alert หลักสิบตัว สบายมากครับ)   ถ้าคุณอยากลองเริ่มทำเลย ตอนนี้คุณมี Metric PromQL (โค้ดที่ใช้ดึงค่าสถิติมารันบนกราฟ) ของตัวที่อยากสั่งเตือนเตรียมไว้หรือยังครับ? หรือถ้าต้องการให้แนะนำ Metrics สำคัญของ Kafka/Strimzi ที่ควรเอามาทำ Alert เป็นตัวแรก ๆ บอกได้เลยนะครับ!
